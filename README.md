# 🎬 Shahin — Cinematic Videographer & Video Editor Portfolio

A modern, high-contrast cinematic portfolio website crafted for **Shahin**, Director of Photography, Commercial Video Editor, and Colorist based in Kerala, India.

## ✨ Features
- **Cinema HUD Hero Section**: Real-time camera viewfinder HUD overlay (`REC [●] 4K 60FPS`, `ISO 800`, `1/120s`, `RAW LOG`).
- **Interactive Video Showcase**:
  - *Ooty Diaries* — Cinematic Travel Documentary (16:9 Landscape)
  - *Night Ride Vibes* — High-Retention Urban Lifestyle Reel (9:16 Vertical)
  - *Chaos in Kaelixo* — Atmospheric Neo-Noir Color Narrative (9:16 Vertical)
- **Silent Hover Preview**: Hovering over project cards initiates live silent playback.
- **Fullscreen Theater Mode**: Custom modal video player with audio and controls.
- **Category Filter**: Instant filtering across *All Projects*, *Cinematic*, *Reels & Vertical*, and *Color Grading*.
- **Director Profile & Arsenal**: Breakdown of cinematography tools, DaVinci Resolve color grading suite, and camera rigs.
- **Direct WhatsApp & Social Booking**: Instant WhatsApp message builder and Instagram links (`@kybercell`).

## 🚀 Live Deployment
- Static web application built with HTML5, Tailwind CSS, Lucide icons, and Vanilla JavaScript.
- Zero dependencies required. Deployable instantly on GitHub Pages, Netlify, or Vercel.
